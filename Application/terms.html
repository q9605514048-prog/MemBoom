4. Local storage and remembered entry

Local vault contents are encrypted on your device. On the website, “Remember sign-in on this device” stores an encrypted unlock secret and a non-exportable browser key in IndexedDB; it may also remember a server session. The password is not stored as plain text, but anyone able to use the same browser profile can open the vault without entering it. This does not protect against malware or hostile scripts running in the same origin. Use this option only on a device you trust. “Lock” clears remembered entry; uncheck the option to use password-based entry again. Private browsing, browser restrictions, or clearing storage can prevent remembered entry.
