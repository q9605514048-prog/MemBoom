MEMBOOM · ПЕРЕНОС КОЛЛЕКЦИИ · ВЕРСИЯ 5

Твои закладки ReManga.
С названиями и статусами.

Новая кнопка собирает карточки при прокрутке и читает ответы списка ReManga. Ограничения в 30 записей в сборщике нет. Полноту проверь по количеству в каждой категории.

Поддерживаемые статусы переноса: «Не интересно», «Хентай (хент)», «Много читать (много глав)», «Лецуха», а также обычные статусы чтения. Сокращённые названия распознаются автоматически; можно выбрать статус вручную.

Если собрано много, а статус не определён

«Категорий из API: 0» означает, что сайт не передал сборщику названия категорий. Это не ошибка чтения тайтлов. Открой конкретную категорию ReManga, собери её прокруткой и выбери статус вручную. В версии 5 выбор применяется ко всем собранным порциям этой категории, а не только к видимым карточкам.

Перед заменой старой кнопки скачай текущий JSON на всякий случай. Не обновляй вкладку ReManga: новая кнопка попробует сохранить прежнюю корзину в этой же странице. Старые записи не знают свою категорию — повторно пройди нужную категорию прокруткой и затем назначь статус. Смотри счётчик «В текущей категории». Для остальных категорий повтори эти действия отдельно.

1. Замени старую кнопку

Ранее сохранённая кнопка сама не обновится. Удали старую закладку «ReManga → MemBoom». Покажи панель закладок: Ctrl + Shift + B, затем перетащи новую кнопку ниже.

↓ ReManga → MemBoom v5

Кнопку нужно перетащить, а не нажать здесь.

Если перетаскивание не работает

Создай обычную закладку браузера. В её поле «Адрес» вставь код целиком, начиная с javascript:.

2. Собери категории

Открой свои закладки ReManga ↗ в браузере, где ты уже вошёл. Нажми новую закладку браузера — появится окно «версия 5».

«Хентай», «Лецуха», «Много читать» — статусы манги. Выбери нужный статус в сборщике. Если название не определилось автоматически, укажи его в поле «Название статуса ReManga». При переходе к следующей категории измени или очисти поле.

  1. Оставь окно сборщика открытым. Переключись на категорию ReManga, например «Читаю». Если она уже выбрана — переключись на другую и обратно.
  2. Проверь статус в сборщике. Он определяется по данным категорий, когда сайт их загрузил. Если рядом написано «Категорий из API: 0», выбери статус вручную.
  3. Нажми «Собрать категорию прокруткой». Сборщик будет прокручивать страницу и сохранять появляющиеся карточки. Можно остановить кнопкой «Стоп».
  4. Сверь количество с ReManga и повтори сбор для остальных категорий, включая «Любимое». Перед каждой категорией проверь выбранный статус. Повторы объединяются.

Не обновляй страницу до скачивания файла: накопленный список хранится в её памяти. Если переход между категориями перезагружает страницу целиком, скачивай отдельный файл для каждой категории. Сначала импортируй основные статусы, затем «Любимое».

3. Скачай файл и проверь перенос

Нажми «Скачать JSON». В MemBoom открой «Манга → Перенести список», выбери новый remanga-memboom.json и проверь названия и статусы в предпросмотре.

«Хентай», «Лецуха», «Много читать» появятся в общем списке статусов манги. Номер последней главы не угадывается. Полный список твоего аккаунта ещё не проверен: если счётчик меньше, продолжи сбор. Старый файл с «title image» не содержит потерянных названий.

Сборщик читает только карточки и ответы запросов списка закладок. Пароли, cookie, токены и заголовки входа не читаются. Он сам не отправляет запросы и не меняет закладки ReManga; JSON скачивается на твой компьютер. Перезагрузка страницы отключает сборщик.
