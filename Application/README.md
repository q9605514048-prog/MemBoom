# Сайт MemBoom

Сайт работает как локальное зашифрованное хранилище. На первом экране выберите «Попробовать без сервера» и создайте мастер-пароль. В этом режиме данные остаются в текущем браузере; аккаунт на сервере не создаётся.

Для переноса используйте «Зашифрованная резервная копия». Полная копия включает аккаунты, заметки и библиотеку сайта. Android импортирует аккаунты и заметки; манга и аниме остаются функцией сайта.

Ссылки Google Диска/Яндекс Диска добавляются в редакторе заметки: название и HTTPS-адрес файла. Файлы не загружаются в MemBoom.

В манге и аниме можно вести прогресс и статусы. ReManga переносится через `remanga-export.html` в браузере пользователя. Чужие закладки и готовые личные выгрузки в проект не включены. Для автоматической загрузки обложек нужен собственный сервер MemBoom.

Локальный запуск сайта с API: `node tools/server/start.mjs` из корня проекта, затем `http://127.0.0.1:8788/`. Для внешнего подключения нужен HTTPS. GitHub Pages размещает только статический сайт и не выполняет серверный код.
