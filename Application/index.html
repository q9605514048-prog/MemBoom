Резервные копии

Одна копия для спокойствия. Ещё одна для нового устройства.

01 / EXPORT

Создать резервную копию

Скачайте зашифрованный файл с аккаунтами, заметками и медиатекой. Для открытия нужен пароль копии.

02 / IMPORT

Импортировать резервную копию

Выберите файл MemBoom и введите его пароль. Перед объединением появится число найденных записей.

Копия и синхронизация

Файл копии храните отдельно от устройства. Синхронизация обменивается данными через ваш сервер и не заменяет резервную копию.

MEMBOOM API

Синхронизация

Ваши устройства. Ваш сервер. Явный обмен данными.

Состояние подключения

Общий сервер для публичного демо не предоставляется. Для обмена подключите собственный MemBoom API.

Подключение к API

Для удалённого сервера нужен HTTPS. При входе в аккаунт используется его сессия.
