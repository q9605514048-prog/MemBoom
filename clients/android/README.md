# MemBoom для Android

Тестовая версия 0.8.1, Android 8.0+.

Скачайте APK из [Releases](https://github.com/q9605514048-prog/MemBoom/releases). Выберите «Попробовать без сервера», создайте мастер-пароль и начните добавлять аккаунты и заметки. При следующем запуске локальный режим попросит мастер-пароль. Интернет для локальной работы не нужен.

Для регистрации и синхронизации подключите свой MemBoom API по HTTPS. Успешный серверный вход запоминается защищённым хранилищем Android. Рабочая сессия открывается автоматически; ручная блокировка просит мастер-пароль.

Импорт с сайта: создайте полную зашифрованную копию, передайте JSON на телефон, откройте «Настройки → Импорт резервной копии» и введите пароль экспорта. Перед подтверждением отображается число аккаунтов и заметок. Импорт сохраняет существующие записи.

Заметки поддерживают закрепление, поиск и ссылки на файлы Google Диска/Яндекс Диска. Манга и аниме доступны только на сайте.

## Сборка

Нужны JDK 17 и Android SDK с платформой 36. Укажите SDK через `ANDROID_HOME` или локальный `local.properties` (он исключён из Git).

```sh
cd clients/android
./gradlew testDebugUnitTest testReleaseUnitTest assembleDebug
```

Windows: `gradlew.bat`. Результат — `app/build/outputs/apk/debug/app-debug.apk`. Это debug APK; для собственного стабильного распространения используйте отдельную release-подпись и храните ключ вне репозитория.

`assembleQa` создаёт отдельное приложение `local.accountvault.android.qa` для проверок без изменения основного профиля. Скрипты UI-проверок находятся в `tools/android/`; их тестовые пароли не используются пользовательскими аккаунтами.
