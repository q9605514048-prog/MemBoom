MemBoom для Windows

Версия 0.9 — первый запуск и автоматический повторный вход.

«Аккаунт MemBoom»: создание аккаунта и вход только по логину и паролю.
Почта и SMTP не требуются. Нужен запущенный сервер MemBoom.
Локальный мастер-пароль сохраняется.
При первом запуске выберите «Создать аккаунт» или «Войти».
После успешного входа следующие запуски открывают хранилище автоматически.
Сохранённый доступ защищён Windows и привязан к текущему пользователю ПК.
Для прежнего хранилища мастер-пароль потребуется один раз при подключении.
«Выйти из аккаунта» отключает автозапуск даже без интернета.
Сессия зашифрована локально; выход отзывает её и удаляет подключение.

1. Распакуйте архив в отдельную папку.
2. Запустите MemBoom.exe. Установка .NET не требуется.
3. При первом запуске создайте аккаунт или войдите. Запомните пароль.

Изменения сохраняются автоматически. Через 5 минут бездействия хранилище блокируется.
В редакторе заметки нажмите «Сохранить заметку», чтобы записать изменения.
Раздел «Заметки» находится слева: создание, поиск, закрепление и редактирование.
Заметки шифруются вместе с хранилищем, но пока не синхронизируются с сервером.
Для их переноса выберите полную резервную копию и Windows 0.6 или новее.
Полные копии с заметками поддерживают Android 0.3+ и обновлённый сайт.
При блокировке несохранённый текст открытой заметки закрывается без сохранения.
Для переноса записей между ПК и телефоном используйте «Экспорт» и «Импорт» с паролем резервной копии.
Импорт сохраняет существующие записи.

Кнопка «Синхронизация» подключается к вашему MemBoom API. Нужны адрес сервера,
токен устройства и общий пароль шифрования синхронизации (как на телефоне).
Для удалённого сервера требуется HTTPS.
Если токена устройства нет, нажмите «Зарегистрировать ПК» и введите
административный токен своего API. Он используется только для регистрации.
Кнопка «Сохранить подключение» запоминает адрес и токен устройства
в локальном зашифрованном хранилище. Общий пароль синхронизации не сохраняется.
«Забыть подключение» удаляет настройки из текущего хранилища, но не отзывает
токен на сервере. Предыдущая зашифрованная версия может содержать подключение.
Для отзыва используйте «Подключённые устройства»: введите административный токен,
обновите список, выберите устройство и нажмите «Отозвать доступ».
Отзыв прекращает доступ к API, но не стирает данные на удалённом устройстве.
Если отозвать этот ПК, для синхронизации потребуется новый токен.
Нажмите «Проверить сервер», затем выберите загрузку, отправку или объединение.
Загрузка заменяет локальные записи, отправка — серверную копию.
Объединение сохраняет отличающиеся записи отдельно. Действия требуют подтверждения.
При конфликте или потере ответа снова проверьте сервер перед повторной отправкой.
Фоновой синхронизации нет. Само приложение не запускает API-сервер.

Данные находятся в %LOCALAPPDATA%\MemBoom\vault-v1.json.
Предыдущая зашифрованная версия — vault-v1.json.previous в той же папке.
Копирование папки с EXE не переносит пользовательское хранилище: используйте экспорт.

Мастер-пароль: от 4 символов, английские буквы, цифры и спецсимволы без пробелов.
Значения аккаунтных паролей и других полей могут содержать любые символы.
Чиби и анимированных персонажей в этом приложении нет.
