# Безопасность тестовой версии

MemBoom — развивающийся прототип без независимого аудита. Для знакомства используйте вымышленные данные.

Хранилище и резервные копии шифруются локально: AES-256-GCM, PBKDF2-HMAC-SHA256, 310 000 итераций, случайные соль и nonce. Это описание реализации, а не гарантия отсутствия ошибок.

В локальном режиме регистрация не нужна. В серверном режиме пароль аккаунта передаётся API для проверки; для удалённого подключения необходим HTTPS. Секрет сервера, токены, ключи подписи и пользовательские данные нельзя публиковать.

Потерянный мастер-пароль не восстанавливается. Очистка браузера и удаление приложения могут удалить локальные данные. Регулярно создавайте зашифрованные копии и проверяйте восстановление.

При сообщении об ошибке не публикуйте личные пароли, токены и копии хранилища. Для чувствительной проблемы используйте Private vulnerability reporting в разделе Security репозитория, если он доступен.
