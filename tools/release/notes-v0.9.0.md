# MemBoom 0.9.0 — English and Russian

- English and Russian interfaces on the website and Android.
- A language selector with a remembered choice. Android also uses your system language for the initial selection.
- Translated forms, buttons, status labels, prompts, errors, and dates.
- Your account names, passwords, notes, and imported content stay in their original language.
- An English GitHub README, repository description, and feature request form.

**Have a feature in mind? I'm happy to add new features based on your requests.** Open a feature request and tell me what you would like to see.

Website: https://q9605514048-prog.github.io/MemBoom/

Android 8.0+: download `MemBoom-Android.apk` below. Choose **Try without a server** to start locally. Use **Settings → Language / Язык** to switch languages. Install over the previous version to keep local data; the signing certificate is unchanged.

Verification: 112 website/API checks, 90 Android tests in each of debug/release, and an emulator check of English → Russian → English with persistence after process restart.

This is a debug preview without an independent security audit. Start with fictional data, keep encrypted backups, and do not lose your master password. Cross-device sync requires your own HTTPS server. Manga and anime remain website-only features.
