# MemBoom 0.8.1 — публичная тестовая версия

Хранилище аккаунтов и заметок с локальным шифрованием.

## Попробовать

- Сайт: https://q9605514048-prog.github.io/MemBoom/
- Android 8.0+: скачайте `MemBoom-Android.apk` ниже и выберите «Попробовать без сервера».

Локальный режим не требует регистрации и сервера. Задайте мастер-пароль, добавьте вымышленный аккаунт или заметку. Повторный запуск Android просит локальный мастер-пароль.

Включены обновлённый красно-золотой интерфейс, поиск, генератор паролей, закрепление заметок, ссылки на облачные файлы, зашифрованные резервные копии и перенос аккаунтов/заметок между сайтом и Android. Манга и аниме доступны только на сайте.

Общего публичного API нет. Для синхронизации нужен свой сервер и HTTPS. GitHub Pages размещает только сайт; загрузка обложек также требует своего API.

Это прототип без независимого аудита: начинайте с вымышленных данных. Мастер-пароль не восстанавливается. Делайте резервные копии перед обновлениями. APK — тестовая debug-сборка с той же подписью, что локальные версии 0.7.x–0.8.0.

Проверки: 109 тестов сайта/API и 90 тестов Android в каждом из debug/release; локальный режим Android проверен в отдельном эмуляторе без Wi-Fi и мобильной сети.

`SHA256SUMS.txt` содержит контрольную сумму APK. Исходники Windows-клиента включены в репозиторий; автономный Windows-релиз пока не предоставляется.
