# MemBoom 0.9.1 — Terms and remembered sign-in

- Terms of Use in English and Russian, accessible before sign-in on the website and offline on Android.
- The website can remember entry after a successful unlock, including after closing the tab. Remembered entry is enabled by default and can be unchecked.
- Lock clears remembered entry. The unlock secret and optional server session are encrypted in browser storage with a non-exportable key.

Anyone using the same browser profile can open a remembered vault. Use the option only on a trusted device. Keep your master password for backups and new devices.

Website: https://q9605514048-prog.github.io/MemBoom/

Android 8.0+: download `MemBoom-Android.apk` below. Install over the previous version to retain local data. The signing certificate is unchanged. Manga and anime remain website-only.

This is a debug preview without an independent security audit. Start with fictional data and keep encrypted backups. The agreement describes preview conditions and does not assert country-specific legal compliance.

Verification: 116 website/API checks, 90 Android tests in each of debug/release, and browser checks of reload, tab reopening, manual lock, and opting out of remembered entry. Both agreement texts are included in the APK.
