# Как попробовать MemBoom

## Сайт

1. Откройте https://q9605514048-prog.github.io/MemBoom/.
2. Нажмите «Попробовать без сервера».
3. Задайте мастер-пароль и откройте хранилище.
4. Добавьте вымышленный аккаунт или заметку.
5. Перед очисткой браузера скачайте зашифрованную резервную копию.

Пароль не восстанавливается. Разные браузеры и адреса имеют отдельное локальное хранилище.

## Android

1. Скачайте `MemBoom-Android.apk` из Releases.
2. Откройте APK на телефоне и при необходимости разрешите установку этому источнику.
3. Выберите «Попробовать без сервера» и создайте мастер-пароль.
4. Для переноса с сайта используйте экспорт JSON и импорт в настройках приложения. Нужен пароль, заданный при экспорте.

Не удаляйте существующую установку для обновления: удаление приложения удаляет его локальные данные. Обновляйте совместимым APK с той же подписью.

## Синхронизация

Локальные данные не появляются на других устройствах автоматически. Поднимите собственный сервер по инструкции в `server/README.md`, настройте HTTPS и войдите в один аккаунт на обоих устройствах. Для расшифрования серверной копии нужен одинаковый мастер-пароль.

Windows-клиент доступен в исходниках; текущий Windows-клиент требует своего сервера. Готовый автономный Windows-релиз в эту публикацию не включён.
