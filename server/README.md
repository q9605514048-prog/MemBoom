# Сервер MemBoom

Node.js 24, сторонние npm-зависимости не требуются. Из корня проекта:

```sh
node tools/server/start.mjs
```

Сайт и API по умолчанию доступны только на `http://127.0.0.1:8788/`. При первом запуске автоматически создаётся `server/.env` со случайным `VAULT_TOKEN`; существующие настройки сохраняются. Пример — `.env.example`.

Регистрация и вход используют логин и пароль MemBoom. Пароли аккаунтов хешируются scrypt; серверные сессии поддерживают отзыв. Содержимое хранилищ приходит зашифрованным, обновляется с проверкой ревизии, конфликты сохраняются отдельно.

Данные находятся в `server/data/`, секреты — в `.env`. Оба исключены из Git. Резервируйте каталог данных и серверный секрет приватно. Не меняйте секрет без учёта существующих сессий.

Для внешнего подключения нужны собственные домен и HTTPS с проверяемым сертификатом. Не выставляйте HTTP-сервер с логинами и паролями в интернет. При отдельном домене сайта задайте точный `AUTH_ALLOWED_ORIGINS`.

Настройка `VAULT_LAN_HOST` относится к явно включаемому режиму разработки в доверенной сети и не требуется для публичного демо. GitHub Pages сервер MemBoom не запускает. Публичный общий API этим репозиторием не предоставляется.

Проверки: `node --test server/tests/*.test.mjs` из корня. Это прототип; перед применением для важных секретов нужен независимый аудит.
