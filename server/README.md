# Сервер MemBoom

Node.js 24, сторонние npm-зависимости не требуются. Из корня проекта:

```sh
node tools/server/start.mjs
```

Сайт и API по умолчанию доступны только на `http://127.0.0.1:8788/`. При первом запуске автоматически создаётся `server/.env` со случайным `VAULT_TOKEN`; существующие настройки сохраняются. Пример — `.env.example`.

Регистрация и вход используют логин и пароль MemBoom. Пароли аккаунтов хешируются scrypt; серверные сессии поддерживают отзыв. Содержимое хранилищ приходит зашифрованным, обновляется с проверкой ревизии, конфликты сохраняются отдельно.

Данные находятся в `server/data/`, секреты — в `.env`. Оба исключены из Git. Резервируйте каталог данных и серверный секрет приватно. Не меняйте секрет без учёта существующих сессий.

Для внешнего подключения нужны собственные домен и HTTPS с проверяемым сертификатом. Не выставляйте HTTP-сервер с логинами и паролями в интернет. При отдельном домене сайта задайте точный `AUTH_ALLOWED_ORIGINS`.

Настройка `VAULT_LAN_HOST` относится к явно включаемому режиму разработки в доверенной сети и не требуется для публичного демо. GitHub Pages сервер MemBoom не запускает. Публичный общий API этим репозиторием не предоставляется.

Проверки: `node --test server/tests/*.test.mjs` из корня. Это прототип; перед применением для важных секретов нужен независимый аудит.

## Автообновление аниме

Сайт умеет читать публичные списки YummyAnime через серверный адаптер. В разделе «Аниме» укажите профиль вида `https://yummyanime.tv/user/id123` и включите автоматическую проверку. При необходимости можно задать `MEMBOOM_ANIME_PROFILE` в приватном `server/.env`: такой профиль будет предложен локальным сервером по умолчанию. Не публикуйте личный конфигурационный файл.

Проверка выполняется примерно раз в минуту, только при открытом сайте и разблокированном хранилище; скрытая вкладка и отсутствие сети приостанавливают опрос. Это периодическое чтение, а не push от YummyAnime. Из источника обновляются статусы, избранное, названия и обложки. Ручной прогресс, заметки и записи манги сохраняются. Удаление на источнике не удаляет локальную запись. Номер просмотренной серии не угадывается.

Добавлены только GET-маршруты `/api/library/anime-source` и `/api/library/anime-profile?url=…`. Второй принимает исключительно публичные числовые профили домена yummyanime.tv. Cookies и пароли YummyAnime не используются. Загружаются все шесть списков, число карточек сверяется со счётчиками; неполные ответы отклоняются. Таймауты, ограничение размера ответа, кеш на 55 секунд и объединение одновременных запросов ограничивают нагрузку. Формат хранилищ и протокол обмена зашифрованными копиями не менялись.

На GitHub Pages этот адаптер не запускается: там нужен отдельно подключённый HTTPS API. Прямой опрос чужого домена из браузера не используется.
